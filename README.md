# SCT_DA_03 – HR Employee Attrition Dashboard

## 📌 Task Objective
Create an interactive HR Employee Attrition Dashboard using Power BI to analyze employee attrition and identify factors influencing employee turnover.

## 📊 Dashboard Features
- Total Employees
- Employees Left
- Attrition Rate
- Attrition by Department
- Attrition by Job Role
- Attrition by OverTime
- Employees Left by Job Satisfaction

## 🎛 Interactive Filters
- Department
- Gender
- Age Group

## 🛠 Tools Used
- Microsoft Power BI
- HR Employee Attrition Dataset
